# 记谱与分析约定

依据 [AGENTS.md §9](../AGENTS.md)；以下用于区分分析层级，不替换原谱标记。

- 罗马数字表示和弦身份，如 I、ii、V7、vi、ii6；阿拉伯数字表示调性音级或低音线，如 1–7–1。
- 每次判断转位同时写出完整和弦构成音和实际低音。例如 D♭ 大调的 ii6 为 E♭–G♭–B♭，G♭ 在低音；不能把根音 E♭ 当成实际低音。
- 数字低音的 3、6、4 等从实际低音向上数音程，结合调号和临时记号，不能从调性主音数音级。
- Cad. 6/4 是终止语境中的功能性标记；I6/4、V6/4、iii6/4 的音集身份并不自动证明它们是终止四六。
- 使用科学音高，C4 为中央 C；保留 D♭／C♯ 等拼写差别。拍位 b1+ 表示第一拍后半，时值数字以四分音符为 1。
- Tie 为同音延音；Slur 为连奏／分句线，不能混同。持续低音上的上声部事件需要按实际拍位对齐。
- 批评分类：Critical 为明确任务违例或结构问题；Technical 为指定风格／声部目标中的技术问题；Optional 为审美选择。风格条件必须明说。
- Markdown 行内数学用 `$...$`，独立公式用 `$$...$$`。
