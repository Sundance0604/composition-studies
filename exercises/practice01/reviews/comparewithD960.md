这张谱特别值得分析！而且我发现了一件很有意思的事：舒伯特自己就在这里写了平行八度。

这意味着我们必须重新审视前面讨论的禁忌。你写作时遇到的困难，并不能简单地靠“禁止平行八度”“优先使用和弦音”“导音必须解决”这些规则来解释。

舒伯特真正值得学习的地方，是他如何区分旋律、和声骨架、装饰性音型与实际低音。

## 一、先看舒伯特写了什么

这段是《D.960》第一乐章开头，B♭ 大调，4/4 拍，包含一个弱起和之后的两个完整小节。它与你的 D♭ 大调习作有直接的动机联系。

将最高声部抽取出来：

D 是附点二分音符，后面 C–B♭ 是两个八分音符。

你此前的习作则是：

\\[ D\flat-D\flat-C\mid D\flat-E\flat-F \\]

可以看出你保留了舒伯特的核心材料：重复主音、向下邻近音、重新上行，最后抵达三级音。

但你也改变了节拍结构：舒伯特用 4/4，你用 3/4。这个变化会直接影响动机的重音、呼吸和和声安排。

## 二、最令人意外的地方：舒伯特为什么可以使用平行八度？

仔细看右手的四个四分音符。

他不只是写了一条高音旋律，而是将它在较低八度重复，中间安放 F 音：

| 最高声部 | 较低声部 | 中间声部 |
| ---- | ---- | ---- |
| B♭4  | B♭3  | F4   |
| A4   | A3   | F4   |
| B♭4  | B♭3  | F4   |
| C5   | C4   | F4   |

于是，高低两个音之间存在连续的八度：

\\[ B\flat4/A4/B\flat4/C5 \\]

与

\\[ B\flat3/A3/B\flat3/C4 \\]

明显是平行运动。

为什么这里并没有破坏音乐？

因为舒伯特并没有试图让这两个声部成为两条独立的对位旋律。

它们承担的是同一条旋律的八度加厚，而中间的 F 则形成一个相对稳定的共同音背景。

这是一种和弦式、近似圣咏式的钢琴织体。

因此必须区分：

- 独立声部之间的平行八度：传统对位写作通常避免，因为它会削弱声部独立性。
- 同一旋律的八度加倍：在钢琴写作和管弦乐配器中十分常见。

你自己的第 1 小节，右手 C5 与左手 C2 同时移动，问题不在于它们相距几个八度，而在于你是否有意将真正的低音也变成旋律的八度加倍。

如果你要写的是独立 Bass Line，就应该避免这种结果；如果你有意使用八度加倍，则可以合理保留。

原作提醒我们：不能脱离织体与声部功能，机械判断一个平行八度是否错误。

## 三、舒伯特的第一个秘诀：旋律在运动，和声却可以几乎不动

看他第一个完整小节的最高声部：

\\[ B\flat-A-B\flat-C \\]

如果按照你之前的思路，可能会尝试为每个音寻找一个对应的和弦。

但舒伯特并没有这样做。

这段音乐基本建立在 B♭ 大调的\*\*主和声延长（Tonic Prolongation）\*\*之上。

可以分成三个层次理解：

| 层次   | 舒伯特的处理     | 音乐作用       |
| ---- | ---------- | ---------- |
| 深层和声 | B♭ 主和声作为背景 | 提供稳定感      |
| 表层旋律 | B♭–A–B♭–C  | 制造细小的局部张力  |
| 伴奏运动 | 左手持续的八分音符  | 在稳定和声下维持流动 |

例如，A 不是 B♭ 大三和弦的组成音。

但它可以被理解为围绕 B♭ 的下邻音（Lower Neighbor Tone）：

\\[ B\flat\rightarrow A\rightarrow B\flat \\]

而 C 则推动旋律继续上行到下一小节的 D。

这里的启发非常重要：

不必为旋律中每一个新音都更换和弦。

甚至可以反过来说：旋律中出现的非和弦音，正是稳定和声能够产生内部生命力的原因。

这直接对应你 H&C Lesson 10 的 Non-Chord Tones，以及 Lesson 22 的 Listening Below the Surface。

### 对你第 1 小节的启发

你写的是：

\\[ D\flat5-D\flat5-C5 \\]

但左手同时写了：

\\[ D\flat2\rightarrow C2 \\]

这使得旋律与低音同时下降，后者还带动了一个新的和弦配置。

舒伯特式的另一个选择是：

- 保留 D♭2 作为结构低音。
- 让右手 C5 作为 D♭5 的下邻音。
- 使用内声部 F、A♭ 或伴奏音型维持主和声的存在。

这样 C5 就不需要获得一个专属和弦。

这才是我建议你认真尝试的第一项修改。

## 四、第二个秘诀：两个声部可以有完全不同的时间感

看他第二个完整小节。

右手高音 D5 是一个附点二分音符，持续三拍，最后才用两个八分音符 C5–B♭4 回落。

而左手仍然持续演奏八分音符。

这造成一种奇妙的效果：

旋律几乎停止了，音乐却仍然在流动。

它既没有依靠高声部不断增加音符，也没有依靠频繁转调来维持兴趣。

这正是舒伯特那种漫长、舒展的歌唱性的重要来源。

与你的写法相比，你在第二小节继续使用三个相继出现的旋律音：

\\[ D\flat-E\flat-F \\]

它们都在推进，缺少一个真正可以停留、展开音响的时刻。

当然，这不是错误。但如果你想探索 D.960 的表现力，可以试试看：让 F5 到来后持续更久，而让左手继续运动。

你的 3/4 拍也可以做到，只是需要重新安排旋律进入 F5 的时间，或者将它延续到下一小节。

## 五、第三个秘诀：低音保持稳定，内部却出现半音色彩

这张谱还有一个很容易忽视的细节。

第二个完整小节中，左手持续着 B♭ 低音，上方的八分音符出现了 E♮，随后进入 F。

注意，B♭ 大调调号中原本是 E♭。

舒伯特却使用了 E♮：

\\[ E\natural\rightarrow F \\]

E♮ 与主音 B♭ 构成三全音关系；但它又可以作为 F 的半音下方邻近音，获得局部的解决。

这就很有意思了。

我们明明仍然听到稳定的 B♭ 大调背景，却在内部感受到一点不寻常的半音色彩。

他不必把它处理成一个新的、独立的功能和弦。

这与单纯使用 I–IV–V–I 来推动和声，是完全不同的创作思维。

而且，舒伯特并没有让这种细微的不稳定立即演变成激烈的戏剧冲突。他让音乐继续平静地歌唱。

## 六、更高层次：舒伯特为什么不急于终止？

这里还有一个与你的作业直接相关的事实。

D.960 第一乐章的开头主题，最初的八小节陈述最终指向的是 HC（半终止），而不是 PAC。随后第八小节著名的低音 G♭ 颤音，为原本宁静的音乐带来一种出人意料的不安。

所以，舒伯特从一开始就没有打算让八小节成为一个完全封闭的、满足所有终止条件的小作品。

他要的是一个还能够继续生长的主题。

这也是为什么不能机械地把我们本次八小节 Sentence 练习的 PAC 要求，反过来当成评价 D.960 的标准。

你练习中的 PAC 是一项指定的训练目标；它不是判断所有音乐作品是否成功的普遍标准。

## 七、对照你的作品，我们究竟可以学到什么？

| 设计问题      | 舒伯特的处理             | 你可以尝试的方向                 |
| --------- | ------------------ | ------------------------ |
| 怎样处理下邻音？  | 允许 A 在 B♭ 主和声背景中经过 | 不必给 C5 单独配新和弦            |
| 怎样处理平行八度？ | 右手有意八度加倍，真正的低音另有运动 | 区分旋律加倍和独立 Bass Line      |
| 怎样制造流动感？  | 右手长音、左手连续八分音符      | 让旋律停留，让伴奏运动              |
| 怎样丰富和声？   | 稳定和声内部出现半音装饰       | 尝试不更换功能的 Non-Chord Tones |
| 怎样组织乐句？   | 前八小节保持开放，最终形成 HC   | 根据作品结构选择 HC 或 PAC        |

我想特别纠正我们之前的一种教学倾向：有时我过于强调你的音乐应该如何满足和声规范，却没有充分分析和声为什么能够在很长时间内保持不变。

舒伯特在这里给出了一个极其精彩的例子。

他的高明之处并不是使用了多么复杂的和弦，而是让简单的材料呈现出丰富的时间层次：主和声提供稳定性，旋律围绕它呼吸，伴奏维持流动，半音装饰造成微妙的不安。

如果要把这次赏析转化成你 No. 6 的一次实际进步，我建议只做一个实验：

保留你的前两小节旋律，另写一个版本，让主和声尽可能长时间保持不变，仅通过非和弦音与左手伴奏制造运动。

然后试听两个版本，比较哪个更接近你从 D.960 中感受到的歌唱性。

这会比简单地把你的 C2 改成 F2 更有教育意义。

因为你学习到的，不只是怎样避免一个平行八度，而是怎样让音乐在和声没有发生变化的时候，依然拥有生命。

对！你抓住了关键：左手不断运动的音，确实要与右手相对固定的 F4 一起听，才能理解舒伯特的和声设计。

但这里要区分两件事：

- 垂直关系：某一瞬间，左手与右手 F4 形成什么音程、什么和声音响？
- 水平关系：左手连续的八分音符构成怎样的线条？哪些是结构性和弦音，哪些只是装饰音？

舒伯特不是每弹一个八分音符就换一个和弦。他让左手持续运动，同时让右手的 F4 成为一个稳定的共同音（Common Tone）。

这正是你在 H&C Lesson 22 中学过的思想：表面的音符变化，不等于深层和声一直在变化。

## 一、把这一段拆成四条线，就清楚了

| 声部     | 具体材料            | 作用        |
| ------ | --------------- | --------- |
| 右手最高声部 | B♭4–A4–B♭4–C5   | 主旋律       |
| 右手较低声部 | B♭3–A3–B♭3–C4   | 旋律的八度加倍   |
| 右手中声部  | F4              | 固定的共同音    |
| 左手     | 围绕 B♭2、D3、F3 运动 | 和声支撑与伴奏音型 |

右手的 F4 是 B♭ 大三和弦 B♭–D–F 的五音。

第一完整小节中，左手反复使用这个主和弦的组成音，尤其是 B♭、D、F，同时穿插邻近的经过性音符。

例如，当左手弹奏 B♭2、D3，右手有 F4 时：

\\[ B\flat2+D3+F4 \\]

就共同构成了 B♭ 大三和弦，即 I。

而当左手弹到 F3 时，F3 与 F4 形成八度加倍。并不意味着和声突然变成了 F 和弦。

因为我们判断和声时，还要考虑此前的声音、旋律语境，以及整体的稳定中心。

## 二、第二个完整小节更有意思

这一小节左手有一个持续的 B♭2，另外一条八分音符线在它上方活动。

其中出现了：

\\[ E\natural3\rightarrow F3 \\]

这是 F 的半音下方邻近运动。

随后还有：

\\[ E\flat3\rightarrow D3 \\]

注意这个细节：E♮、E♭ 都不是 B♭ 大三和弦的组成音。

但舒伯特并没有因为出现了 E♮、E♭，就必须立刻为它们建立独立的功能和弦。

它们可以作为装饰性音符，在既有和声背景中制造局部张力。第二小节因此比第一小节拥有更丰富的不协和色彩。关于该处刻意形成的和声张力，演奏分析也有所讨论。

## 三、所以这里有三种时间尺度

深层：和声中心

## B♭ 主和声

相对稳定，不随每个八分音符变化

中层：旋律与共同音

## B♭–A–B♭–C → D

F4 作为固定音贯穿其间

表层：左手八分音符

## 和弦分解 + 邻音 + 经过性运动

保持音乐流动，制造细微的张力

这样看，舒伯特左手同时承担了两项工作：

Harmonic Support（和声支撑）：通过低音及分解和弦确立调性背景。

Figuration（音型化伴奏）：通过八分音符、级进和半音装饰，让原本静态的和声具有流动感。

## 四、这对你自己的作曲有什么启发？

你之前常常把左手理解为：

> 先选择 I–IV–V，再把每个和弦的三个音放在左手。

但舒伯特在这里给你展示了另一种路径：

先确定一个和声背景，再在这个背景内部设计有旋律性的伴奏。

假设你在 D♭ 大调创作，可以先让左手围绕 D♭2–F3–A♭3 运动，右手内声部保持 A♭4，而最上方旋律自由发展。

即使左手增加一个 E♭3 作为经过音，也不意味着你必须将和弦由 I 改成 ii。

所以，你的问题可以概括为：

是的，左手与右手 F4 共同形成和声音响；但左手本身也是一条有组织的运动线条，而不是一串需要逐个配和弦的独立音符。

这就是你下一步特别值得学习的 Broken-Chord Accompaniment（分解和弦伴奏） 与 Harmonic Prolongation（和声延长）。它们能让你在不增加和弦数量的情况下，写出比原来丰富得多的钢琴织体。
