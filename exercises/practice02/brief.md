# practice02 — 让伴奏也有动机

设计日期：2026-11-11。状态：Planned。`practice02` 是文件档案标识，不替历史题号 No. 6／首次正式习作关系作决定。

## A. 学习目标与来源

主要新写作概念：**伴奏动机化**。给伴奏一个可辨认的节奏与音型轮廓，让它在重复中适应和声和乐句，而不仅为每个旋律音重新摆放一个和弦。

深化此前已经接触的**主和声延长与节奏层次**：使一个和声支撑较长的音乐时间，同时让旋律、低音和伴奏有不同的运动密度。这是从讨论进入实际写作的尝试，不把此前已接触的概念冒称全新知识。

相比上一套，本次希望新增的写作能力是：能主动设计一层有持续性、有辨识度的伴奏，并用它支持旋律的停留、变化和呼吸；能通过试听比较不同织体的表现效果。

## B. 音乐约束

| 项目 | 本次安排 |
|---|---|
| 编制 | 钢琴，两谱表；先让旋律与实际低音可辨，内声部按需要增加 |
| 调性 | 默认 D♭ 大调，方便与原作业比较；如记谱负担妨碍构思，可在开始时自行选定另一大调并注明 |
| 拍号 | 默认 3/4；若音乐构思需要，可改为 4/4，写一句理由即可 |
| 主作品长度 | 默认 8 小节；若呼吸或结束确实需要，可扩为 10–12 小节，不为凑数重复材料 |
| 形式 | 前一部分建立乐思及织体，后一部分使材料发生变化并形成选定的结束。默认前 4／后 4；不强制标为 Sentence 或 Period |
| 和声 | 前半段至少连续两个完整小节由同一主和声支撑；允许分解、转位和外音装饰。余下和声由用户决定，没有固定逐小节和声表或必须用几个和弦的配额 |
| 旋律 | 可以从 practice01 的动机另作发展，也可原创。至少有一处一个旋律音保持两拍或以上，而伴奏在此期间继续运动；后半段应能听出与前段的材料联系及某种变化 |
| 伴奏 | 设计一个可辨认的短节奏／音型细胞，在前半段复现。后半段至少有一次有目的的调整，如停顿、密度、方向或音区变化；不要求整段机械循环 |
| 低音 | 能指出重要低音的位置和方向，以及哪些运动只是分解和弦或装饰。不要求每次低音都取和弦根音，也不要求低音全程移动或全程保持 |
| 声部进行 | 对拟作独立线条的声部，留意无意的平行及倾向音处理。若采用八度加倍，标明它是同一旋律的织体加厚。按具体语境判断，不一概禁止六四和弦、导音跳进或持续低音上的装饰 |
| 结束 | 自选开放的属和声结束，或通过属—主回到主和声，并注明意图。若标作 HC、IAC 或 PAC，再按相应条件核验；不强制 PAC |

同一和声支撑两个小节不等于要求所有音都是和弦音，也不意味着每个分解音都获得独立和弦标签。对复杂情况先记录自己的意图，后续可以讨论不同分析。

长度的理由：前半段需要时间使伴奏细胞被听见、复现并支撑旋律停留，后半段需要让材料变化并产生方向。八小节是这次写作的起点，不是固定晋级单位；扩展必须服务音乐结构。

## C. 写作与比较过程

### 1. 建立前半段

先构思前四小节的旋律和重要低音，标出主和声支撑的两个小节，再寻找适合它的伴奏细胞。允许旋律、和声与伴奏来回调整；无需先把完整罗马数字表填好才写音乐。

长旋律音出现时，试听伴奏是否仍给音乐以方向。若感觉只有循环，可以尝试局部停顿、音区变化或句尾收束；这些是可选手段，不是必须逐个使用的清单。

### 2. 完成主作品

将前半段发展成默认八小节的音乐。选择一种最有用的变化手段即可：改变动机节奏、从细胞取片段、移动音区、改变伴奏密度等。此前已接触的 fragmentation／sequence／liquidation 可使用，不要求在同一短段里全部展示。

后半段的和声与结束由作品需要决定。当前目标是协调音乐层次，不额外强制 V/V、七和弦或终止四六。

### 3. 做一次受控的织体比较

另存前四小节的四小节对比稿：保持旋律、拍号、速度、主要低音与和声骨架，将主稿的音型化伴奏改为较简洁的长音或块状和弦。表层最低音可因分解方式而不同，分析中仍分清实际最低音与结构低音。尽量保持力度与音色一致，便于听出织体差别。

试听两稿，比较歌唱性、呼吸、前进感与旋律清晰度。简洁版也可能更适合某些位置；评价依据是预期效果，不预设音符更多的版本更好。

这份四小节稿服务于同一作品的比较，主作品仍是八小节；不把它登记为另一项已完成作业。

## D. 必须目标与艺术选择

必须目标：

1. 主稿中有上述两个小节的稳定主和声，以及长旋律音上继续活动的伴奏。
2. 伴奏具有可辨认的细胞，后半段的调整能说明音乐目的。
3. 音符、时值、Tie／Slur 与声部标记准确表达意图；能用短分析分清重要低音、和弦和外音。
4. 完成四小节同材料的织体对比，并说明试听结果。

可选艺术选择：是否保留旧动机、八度加倍、内声部固定音、半音装饰、低音保持、高潮位置、具体伴奏类型、句末开放或闭合。它们不作为隐藏扣分项目。

批改按四类说明：明确记谱错误、特定风格中的技术问题、本作业指定目标未实现、可成立的艺术选择。音高关系与风格评价分开；不为满足规则自动改写用户旋律。
