## A. 学习目标与教材依据

### 两个主要写作重点

1. **用声部线条组织较丰富的和声**：在两小节中写出多于三次的和声陈述，使低音、内声部与旋律共同解释和声变化；能比较其中哪些变化重要，哪些可以删减。
2. **伴奏中的动机回应**：从旋律中取一个短节奏／音型细胞，在低声部或伴奏内声部作一次可辨认的回应。重复可以变形，不要求写成严格卡农。

Sentence、转位、经过音、邻音和 IAC 用于复习，不把本次尝试登记为已独立掌握。比上次增加的能力是：同时控制和声事件的密度、低音的走向与伴奏的材料联系，并通过简化版本判断音乐是否真的需要某些和声。

## B. 音乐约束

| 项目 | 当前要求 |
|---|---|
| 调性 | **B♭ 大调**，调号 B♭、E♭。本次主稿保持本调；半音外音不自动等于转调 |
| 拍号 | **4/4** |
| 编制 | 钢琴，两谱表；旋律与实际低音可辨。需要独立节奏时，用适当 voice 与时值写清，不要求每拍满四声部 |
| 长度、形式 | **8 小节 Sentence，2+2+4**。前四小节让乐思被听见和复现，后四小节给较密的和声单元、发展与终止留出时间 |
| m1–2 | 提出自己的两小节 Basic Idea；可从熟悉作品或旧作取材料后变形，并注明来源 |
| m3–4 | 可辨认地重复或变奏 m1–2；选择保留的节奏／轮廓由用户决定，不在 m4 强制另作句末终止 |
| m5–6 | **D 核心单元**：两个完整小节内至少 4 次有区别的和声陈述，包含 I、ii、IV、V 四种和弦身份，清楚标拍位与罗马数字。转位、先后顺序和时值自行设计；指定这四种身份是本次复习配额，不冒称教材原话 |
| m7–8 | 准备并形成 **IAC**：句末 V→I 均为原位，最高旋律音落 D 或 F，形成弱于主音结束的正格终止。建议在 m8 强拍到达并留有停驻时间 |
| 和声框架 | 采用本调材料，以 T—PD—D—T 的整体方向组织；先后次序、时值、具体转位与和声节奏由用户设计。不提供要求照抄的逐拍和声表 |
| 低音 | 至少有一段连续三个不同低音音高的级进，例如 B♭–C–D 或 D–E♭–F，中间允许保持；至少两处外声部反向或斜向运动。判断依据是实际最低音，不是和弦根音 |
| 伴奏 | 至少一处动机回应，可放在旋律长音或休止处；至少一条其他伴奏线参与低音变化，可用共同音保持、级进或有目的的跳进说明 |

**怎样计算 D 单元的和声数**：主和弦反复敲击、分解同一和弦、单个旋律经过音或邻音，均不能据此多算一个和声。转位或声部变化是否产生可单独分析的和声事件，须由完整声部关系和语境支持，不只看瞬间音集。前后返回同一和弦可分别作为陈述计时，但还必须有中间真实的和声变化，不能靠重复标签凑数。

本次 D 单元中的四种身份以和弦根音和性质区分：I 与 I6 都属于 I，不能两次占用不同身份的配额。若采用主功能延长中的经过和声，可在分析中同时标出表层事件和深层骨架。m5–6 不要求全曲每两拍换一次和弦，其余位置允许更舒展。

## C. 必须在曲目中出现的 H&C 内容

以下是本次可核验的必需内容；一个位置可以同时承担多项，不用逐项另造一段音乐。

| 必需内容 | 关联课次 | 怎样在本稿实现／证明 |
|---|---|---|
| I、ii、IV、V；至少 I6、ii6 两种第一转位 | L5–7、L16 | 谱中实际写出；标根音、完整构成音与实际低音。I6、ii6 是转位要求，不能把它们误算为四种新的和弦根音 |
| 至少一次 V6→I | L19，联系 L14–15 | 低音 A→B♭；在实际 voice 中检查导音与其他声部的连接。这不取代句末原位 V→I 的 IAC |
| 一处经过音、一处邻音 | L10 | 各标出准备／进入音、外音、离开／解决音以及当时的和声。只是邻接轮廓而外音属于和弦时，不计为和声邻音 |
| 可解释的低音线与声部运动 | L4、L14、L18 | 上表的级进与反向／斜向运动；核查拟作独立声部之间无意的同向纯五／八度。八度加倍需说明织体角色，不一概禁止 |
| 主功能延长与结构归约 | L17、L22 | m1–4 以建立／延长主功能为目标，允许有装饰性和声；把 m5–6 的表层和声另归约成较简的功能骨架 |
| 一条数字低音装饰线 | L6、L9、L23 | 从上述外音中选一处，以实际低音为基准，写两个以上相继的上方音程数字；解释数字不是调性音级，也不自动表示换和弦 |
| Sentence 与句末 IAC | L11–12 | 标 BI、复现、continuation、cadence；m5 起选择 fragmentation、sequence 或其他已学变化手段中的一种，不能只凭小节数声称 Sentence 成立 |

本调常用材料仅作查阅：

| 身份 | 完整音集 | 实际低音（若指定转位） |
|---|---|---|
| I／I6 | B♭–D–F | I：B♭；I6：D |
| ii／ii6 | C–E♭–G | ii：C；ii6：E♭ |
| IV | E♭–G–B♭ | E♭ |
| V／V6 | F–A–C | V：F；V6：A |

## D. 对照版本、自由与评价

### 两小节简化稿：本次需要提交

将 m5–6 另作 **2 小节、2–3 次和声陈述**的版本，优先保留原旋律、节奏与端点和声。需要改动旋律时，由用户决定并标出改了什么；若删减后某音成为外音，检查它的连接方式，不强行保留无从解释的不协和。

试听主稿与简化稿，回答：低音是否更自然？动机是否更清楚？较丰富版本的哪一次和声变化产生了简化稿没有的效果？可以偏爱简化稿；主稿完成 D 的技术尝试与艺术取舍是两件分别记录的事。

### 可自由决定

旋律、节奏型、音域、速度、力度、高潮位置、伴奏的具体音型、动机来源以及回应方式。可以带着本作业的问题继续修改 practice01，无需先结清旧作。

### 评价分类

1. 明确记谱错误。
2. 相对于本次古典独立声部目标的技术问题：说明声部身份、功能与语境。
3. 未实现本作业明确目标，例如 D 核心不足四次有效和声陈述、没有实际外音、句末未形成所选 IAC。
4. 可以成立、值得讨论的艺术选择，例如加倍、织体密度、长音、停顿或简化后的效果。

不自动改写旋律，不把所有六四和弦、导音跳进或外音一概判错；先辨清其在这份谱里的角色。本次 IAC 是训练要求，不是评价一切音乐的普遍标准。
